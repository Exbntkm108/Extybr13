# Book Tracker

Автор: [Сурикова Мария]

## Описание

"Book Tracker" - это приложение, которое позволяет управлять списком прочитанных книг. Пользователи могут добавлять информацию о книгах, фильтровать по жанру и сохранять данные в формате JSON.

## Инструкция по запуску

1. Убедитесь, что Python установлен на вашей машине.
2. Установите необходимые библиотеки (если требуется)
   3. Запустите приложение

## Примеры использования

1. Введите название книги, автора, жанр и количество страниц.
2. Нажмите кнопку "Добавить книгу" для добавления книги в список.
3. Для фильтрации по жанру введите необходимый жанр в фильтр и нажмите "Применить фильтр".
4. Добавленные книги могут быть просматриваемы по количеству страниц, и пользователь может удалить их из списка.
